# 0.3.4 首次使用引导与验收

本版沿用 Kotlin / Jetpack Compose / Material 3 及当前浅绿配色，新增三页引导，没有增加依赖或复杂动画。

## 使用行为

- 第一次运行展示三页介绍，右上角可跳过，底部显示进度并提供上一页与下一步。
- 完成和跳过均通过现有 DataStore 保存 `guideCompleted`。记录写入失败时保留引导并提示重试；保存过程中禁用重复操作。
- 首次记录独立于账号、AI 配置和外观。首次进入的初始化阶段显示加载状态，避免先闪出登录或首页。
- 设置 → 数据与账号 → 使用指南可随时重看。重看不写首次记录，结束或跳过后返回首页。
- 未登录的首页提供登录、设置与使用指南入口；已登录但尚未配置完整 AI 服务时提供可暂时关闭的配置提示。AI 配置不阻挡查看和同步任务。
- 引导期间不启动首页自动同步，结束后恢复原有前台流程。登录验证、网络读取、回填和提交状态核对实现保持原样。

文案按实际功能限定为“未结课课程”和“已读取的截止时间”，图片开关使用设置中的实际名称“图片题输入”。生成、回填和保存草稿不会标记完成，仍由官方提交状态决定。
