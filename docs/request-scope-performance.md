# 请求范围与性能记录（0.3.3）

日期：2026-10-29。版本：0.3.3 / versionCode 18。

## 请求与恢复

单个作业完成后的状态核对只请求其所属课程。删除原先签名缺失/失效时调用全量 `homework()` 扫描的回退路径。

| 场景 | 典型无分页请求数 | 范围 |
| --- | ---: | --- |
| 有效签名 | 1 | 目标课程作业列表 |
| 签名缓存缺失 | 2 | 目标课程入口取得 enc/stuenc，再读该课程列表 |
| 已有签名失效 | 3 | 旧列表失败，恢复目标课程签名，再读该课程列表 |
| 同课程触发重叠 | 共用上述请求 | 页面加载、返回首页、定时核对共用在途任务 |
| 成功核对后 1.5 秒内再次触发 | 0 次新增请求 | 复用刚取得的状态；后续定时核对仍读取新状态 |

课程入口元数据（课程/班级、cpi、生命周期）和两分钟有效的学校标识缓存在 App 私有存储，恢复 Reader 后可复用；签名仍只在内存保留十分钟。缓存按账号隔离，退出账号或清理缓存会清除。持久缓存不含 enc/stuenc、Cookie、作业状态或题目内容。已知结课/未开放的课程不会因恢复签名而继续读取。

如果旧版本升级后尚无入口元数据，直接通过已有作业的课程/班级编号访问目标课程入口，补取页面提供的 cpi；不自动扫描其他课程。目标入口本身无法识别或无权访问时保留旧状态并报告失败，必要时可由用户发起完整同步。

已取消页面订阅不会取消返回首页正在复用的共享任务；退出前台、账号切换或清理缓存会使共享任务取消/失效。失败不进入成功缓存，成功合并窗口仅 1.5 秒，不把状态长期缓存为已完成。

## 阶段调度

完整同步先核对课程生命周期，优先读取当前操作课程，按课程发布作业状态，包括明确为空的课程。首页列表不再等待考试阶段；考试和截止时间/成绩补充各自启动独立任务，考试有独立加载状态和错误提示。作业读取失败但课程范围可信时，考试仍可单独继续。

状态核对、考试和详情不再共用一个跨阶段协调器锁。底层网络仍受同一个单并发、至少 1 秒间隔的读取门控。没有提高并发或缩短间隔，没有重新创建或调整 OkHttpClient 复用策略。

详情通过 Room 原子字段更新合并，仅在作业及原提交状态仍匹配时写入截止时间/成绩等元数据；不会覆盖新的提交状态、删除其他课程或恢复已清理的行。

## 耗时日志与证据

日志标签 `XieLeMa.ReadTiming`，仅记录固定阶段名、操作类别、毫秒数和成功标记，不包含网址、账号/课程标识、签名、Cookie 或 HTML。

阶段包括 `gate_wait`（等待全局许可）、`throttle_wait`（请求间隔等待）、`retry_wait`（重试退避）、`network_body`（网络到完整响应正文）和 `html_parse`（实际 HTML 解析）。另记录签名命中/缺失、在途合并和成功窗口命中次数。

本地 `ReadTimingTest` 使用两次带约 60 ms 模拟 RTT 的拦截响应，并执行实际 HTML 解析。采集结果：网络正文读取累计 **128.437 ms**，HTML 解析累计 **0.729 ms**，二者占比 **99.44% / 0.56%**；请求间隔等待另计 **946.923 ms**。完整日志见 [原始样本](performance/read-timing-synthetic.log) 与 [汇总](performance/read-timing-synthetic-summary.txt)。这是合成测试结果，不代表真实学校接口耗时，也不能据此认定实际瓶颈或直接调整风控相关参数。

实际账号操作期间可采集日志后运行汇总：

```powershell
adb logcat -d -v brief -s XieLeMa.ReadTiming:D '*:S' | Set-Content -Encoding utf8 read-timing.log
python tools/summarize_read_timings.py read-timing.log
```

脚本按阶段和操作类别输出次数、累计、均值、最大值和失败数，并给出网络/解析累计占比。排队可能与其他请求执行重叠，因此累计阶段耗时不等于整次刷新墙钟时间。应在真实账号场景重复采样后再决定是否精简解析范围或调整并发/间隔。
