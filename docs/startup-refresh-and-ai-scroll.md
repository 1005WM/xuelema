# 启动刷新与 AI 答案滚动修复（0.3.11）

## 作业读取

原 autoRefreshOnce 实际只提供 1.5 秒防抖；路由每次回到首页都会重新触发。详情页另有 5 秒状态核对、网页加载完成核对和返回首页最多三次重查。

现在启动读取仅依赖账号、初始化和使用指南就绪，与当前路由无关。每个账号在同一 ViewModel 会话中自动尝试一次；失败或取消后也不因导航而自动重试。账号切换可以为新账号读取，退出登录重置本次会话标记。配置变化和返回首页不会重新读取。离开应用或进入其他页面仍取消在途同步。

移除详情页轮询、返回核对及页面完成后的自动元数据读取。首页继续展示 Room 缓存，作业提交后的状态通过用户手动刷新更新。下拉刷新、刷新菜单、强制刷新、验证后重试和官方页面同步按钮保持可用。启动或手动同步所包含的截止信息补充与考试读取仍属于同一轮显式同步。

## AI 答案滚动

禁用答案底部弹窗的拖拽手势以及列表边缘弹性效果，增加明确的关闭按钮。弹窗内容高度基于窗口高度，不依赖滚动内容测量。用户拖动答案列表时释放旧答案输入框焦点，避免输入法和 bring-into-view 把列表拉回之前的编辑位置；点击待处理题目跳转也先释放焦点。逐题编辑、复制、回填、停止和原文对照保持可用。

## 验证

新增/更新设备回归：等待超过旧防抖时间后反复返回首页不读取、Activity 重建式调用不读取、显式强制刷新更新真实仓库；答案列表到底后反复滑动、状态更新、输入框焦点和关闭动作。

工作流运行完整 JavaScript 回归、Android 构建、单元测试、Lint、设备测试源码编译，并在 API 35 模拟器执行上述设备回归。实际结果以本分支 Actions 记录为准。0.3.11 包含此前多空题回填修复。构建包仍为 CI Debug 签名，无法在没有原密钥时保证与旧包签名一致。

## 填空题解题步骤

填空题提示词要求在 explanation 中给出可核对的分步解答，包括依据/公式、关键计算与结论核对；非计算题说明知识依据。answer 仅保留当前空的最终答案。每个填空作答区域单独生成，使用各自的输出预算；步骤展示在“解题步骤”区域，不参与网页答案回填。没有步骤的填空响应不会被标记为完整，可补全重试；正常接收上游 reason 字段。新增单元测试验证提示词、独立生成、多空 ID、换行保留以及缺失步骤的处理。
