# 0.3.6 截止日期读取修复

用户在 0.3.5 中仍看到“截止 待获取”，并提供官方原文：`作答时间：10-27 11：50 至11-01 23：59`。其时钟部分使用全角冒号，旧正则只接受半角冒号，因此未匹配到日期；HTTP 返回页面后，即使没有解析出有效元数据，也会被当作成功详情缓存十分钟。

解析前统一时间中的全角冒号和不换行空格，覆盖可见详情、列表行、隐藏截止字段等入口。修复后原文得到 `11-01 23:59（年份待确认）`，仍不猜测年份、不改变提交状态、不凭无年份日期计算逾期。已有完整年份、日期有效性检查、排除题干日期的规则保留。

未完成作业如果仍未解析到截止信息，按未补齐处理，只保留一分钟重试冷却，不再使用十分钟成功缓存。已有日期继续保留；短时间多次刷新仍有请求节流。考试、AI、回填间隔、账号和数据库结构均未修改。
