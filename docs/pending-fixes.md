# 0.1.3 未完成作业解析修复

用户反馈：自动同步检查 41 页后停留在 COURSE_LINKS，存在一个待适配入口；手动同步当前页能读取已完成作业，但读不到未完成作业。

## 已定位并修复的代码缺口

1. 原解析器只读 `href`、`data-url`、`data-href` 和 onclick 中的字面 URL，漏掉 `li[onclick="goTask(this);"][data]` 形式的作业条目。新增 `data` / `dataurl` 地址读取，兼容整段百分号编码的官方链接及 `/work/task` 入口，标题支持 `p.overHidden2`。同一段提取代码同时用于自动同步和手动同步。
2. 原状态表达式会为一个空白 `.status` 节点生成空格字符串；空格被视为有效状态，阻止读取行内“未提交”等文字。现在去掉空白后才选择回退来源。
3. 明确显示“暂无作业”的受支持作业列表，原先也走“未读取到作业”的错误分支。现在单独报告当前列表为空；缺少标识、加载中、未知结构和课程列表空态不冒充空作业列表。其他课程缓存仍保留。
4. 手动同步结果显示“未完成 N 项、已完成 N 项、状态待识别 N 项”，便于区分未读到条目和状态未知。结构诊断增加“属性链接”计数，不输出原始 URL、签名或账号数据。

## 证据与范围

- `data` / `goTask` 和 `p.overHidden2` 结构依据：[适配项目作者公开的结构说明](https://github.com/DanMo661/Xuexitong-mcp/blob/main/README.md#作业enc-已解) 及其 [client.py 实现](https://github.com/DanMo661/Xuexitong-mcp/blob/main/xuexitong_mcp/client.py)。本项目独立实现 DOM 读取，没有引入该客户端、登录方式或私有接口调用。
- 新增 `homework_data_links.html` 是按上述结构手工构造的脱敏回归样本，**不是用户账号页面取样**。旧脚本在混合列表中只读到已完成的 1 条；修复后读到未完成和已完成共 2 条。
- 回归检查属性变体、整段编码、正常链接参数不被二次解码、状态回退、待批阅、隐藏标签、伪造域名、错误编码、非 URL 数据、缺少标识和空态。不能依据 `answerId=0` 猜测为未提交。
- 当前没有连接用户设备，也没有真实账号 DOM。以上修复解决了可复现的代码缺口，尚不能断言用户学校的全部模板已经适配。仅有 JS 函数、没有可观察地址的作业菜单，以及跨域 iframe、滚动分页仍需在官方页面打开后同步。

## 安装与操作

1. 用 `dist/HomeworkAssistant-0.1.3-debug.apk` 覆盖安装（versionCode 4，沿用原 Debug 签名），无须卸载。
2. 打开官方页面，进入某门课程的作业列表，切到“未完成/未提交”，等待网页内容显示后点“同步当前页”。
3. 成功提示会列出未完成、已完成和未知状态数。返回首页切到“未完成”，可查看同一 Room 快照驱动的列表和顶部总览。
4. 如果仍是 0，保留本次结果中的三种状态数量或结构计数；它能进一步定位实际模板差异。无需提供 Cookie、密码、Key 或带参数的网址。

构建和测试结果见 [verification.md](verification.md)。
