# 官方页面适配与完整性

> 历史 DOM 适配说明。0.2.0 的作业与考试主同步已切换为 [xuexitong-cli 读取流程的 Android 原生移植](mcp-integration.md)，以下作业 DOM 桥不在主路径运行。

当前适配器：`chaoxing-dom-v4-unverified`，经过基于公开结构的合成 DOM 测试，没有连接用户设备验收。本次全页入口与框架读取见 [aggregate-fixes.md](aggregate-fixes.md)，此前说明见 [pending-fixes.md](pending-fixes.md) 和 [sync-fixes.md](sync-fixes.md)。

## 适配方法

1. 由使用者在官方 WebView 主动登录，不收集账号密码。
2. 只检查需要支持页面的 DOM 结构。取样前移除姓名、学号、账号 ID、Cookie、令牌、个人答案和受限内容。
3. 确认课程/班级稳定标识、作业标识、分页和明确空态；缺少稳定标识时不要退回标题哈希。
4. 在脚本中更新选择器，配套加入脱敏 HTML fixture 和回归测试。
5. 对同一页面明确区分 READY、EMPTY 和 UNSUPPORTED，未知结构不能返回“成功空数据”。
6. 校验 iframe 的实际来源。父页面不能跨域访问其 DOM；新版由来源限定的文档起始脚本在每个官方框架里读取自己的 DOM，能力不足时仍可打开观察到的框架地址后读取。

## 完整性

当前只有明确的“没有更多/已加载全部/全部加载完成”、明确空态或测试 fixture 的完成标记才确认页面枚举终止。单纯不存在下一页链接不是完整性证据。

v2 另外识别分页组件中明确禁用的下一页；区分课程列表与作业列表的终止证据，单课程“暂无作业”不会当成账号“没有课程”。空容器本身不作为 AJAX 加载完成的证据。

v2 会将观察到的官方 HTTP 链接升级 HTTPS，读取 data-url/data-href、onclick 中的字面 URL，以及页面 URL/隐藏字段/行属性中的课程与作业标识。不会执行提取到的任意 onclick 或猜测私有 API。只有 JavaScript 函数调用且没有可观察地址的导航，仍可能需要使用者在官方页面打开列表后同步当前页。

“同步当前页”优先让可见的官方子文档分别读取并通过限定来源的消息通道合并，不突破父文档的同源限制。旧 WebView 降级为主页面与同源子文档；未读取框架阻止声明完整覆盖，仍可打开观察到的框架地址。若缺少稳定课程/作业标识，不发布伪造 ID，页面显示计数与视口等诊断信息，不输出原始账号或 URL 参数。

v3 补充 `data` / `dataurl` 和 `goTask(this)` 作业行。只对整段编码地址解码一次，正常 URL 的参数保留转义，之后仍执行 HTTPS 和官方来源检查。作业标题兼容 `p.overHidden2`；空白 `.status` 不遮盖正文中的状态。`answerId=0`、单独“已截止”等信息不足以证明未提交，仍保留 UNKNOWN。属性不是 URL、缺少 ID 或被隐藏的作业行，不伪造记录。

当前页同步分别报告未完成、已完成和状态未知数量。明确空作业列表不会再显示解析失败，但也不因此删除其他课程缓存或宣布整个账号“全部完成”。

v4 补充官方聚合列表的 taskrefId / workHandle 路由和 option 状态布局。刷新优先访问官方聚合作业 HTML 页面，并复用当前进程中成功读取的作业列表入口；分页仍只跟随观察到的链接。相对截止时间不擅自推算，缺少明确日期则保留未知。

网页使用虚拟列表、滚动加载或隐藏 Tab 时，需要加入该版本专属的加载/切换策略，并用页面总数或其他可验证依据核对。当前通用适配器不自动点击未知按钮、不执行提取到的任意 onclick。

课程 ID 与班级 ID 联合组成 Course.id，作业 ID 与 Course.id 联合组成 Homework.id。不同页面出现同一作业状态冲突时本次同步失败，不随意采用最后一条。

## 回填

回填前重新提取全部题目，比较当前 URL 和文本/选项指纹。选择题必须能匹配选项标签；填空数量必须一致；不支持的富文本 iframe 直接降级复制。

指纹用于防止意外错位，不是服务端真实性或防篡改证明。回读校验仅说明 DOM 已改变，不能证明官方后台保存成功。最终保存与提交由使用者完成。
