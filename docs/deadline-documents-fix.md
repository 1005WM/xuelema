# 截止日期补充读取（0.3.9）

日期：2026-10-31（Asia/Shanghai）。用户反馈 0.3.8 仍显示“截止 待获取”。此前提供的官方文字为 `作答时间：10-27 11：50 至11-01 23：59`，该字符串的直接 HTML 解析已通过旧版测试，因此本轮检查了取得文字之前的读取路径。

## 本轮修复

- 日期解析增加拆分标签造成的标签/时钟空格、零宽字符及 `data-end-time` 属性支持，保留全角冒号、严格日期校验、题干和答案排除规则。
- HTTP 详情入口没有截止日期时，继续读取 HTML 中明确给出的官方作业 `iframe/frame` 或 `meta refresh` 文档。校验作业、课程和班级标识，不执行脚本、不推测接口、不自动点击开始或提交。最多读取 3 个文档/作业，所有实际详情请求计入原有 160 次上限；沿用 8 秒单项、120 秒总预算、共享客户端、限流与验证暂停规则。
- 打开官方作业页后，读取已经显示的元数据，短暂重试以等待动态渲染；可补充同源作业内嵌页。该路径不额外请求平台，不读取题目中的日期。仅在账号、作业与页面仍匹配时写入当前账号 Room 记录，状态发生变化时由已有详情合并规则阻止旧状态覆盖。
- 首页由现有 Room Flow 自动更新；保留无年份日期文本 `11-01 23:59（年份待确认）`，不猜测年份，也不将日期当作提交凭据。首页红字仍不显示。
