# 超星 AI 识别与回填移植（0.2.5）

日期：2026-10-28。版本：0.2.5 / versionCode 11。

## 使用方法

1. 覆盖安装当前 `dist/XieLeMa-0.2.7-debug.apk`，无需卸载同签名前版。
2. 在设置中保存 API 地址和 Key，获取模型列表并选择模型。
3. 打开具体作业，等待官方题目出现，点击 **AI 作答 → 开始生成**。
4. 核对并编辑答案，点击 **回填页面**。回填后回到官方页面检查，并手动保存或提交；不能可靠写入的题目可复制并分屏对照。
5. 图片题需在设置中开启 **图片题输入** 并保存。仅在确认具体模型支持图片时开启；开关不代表模型已经通过图片能力测试。

## 上游与复用范围

来源：[zhu-hailin/chaoxing-ai-assistant](https://github.com/zhu-hailin/chaoxing-ai-assistant)。固定到提交 `5ca9a6e8252be2a73c57bdd14b3d23fe271e1930`，不从网络热更新或执行远程脚本。

以下三个 MIT 模块原样保存在 `app/src/main/assets/scripts/chaoxing_ai/`：

- `question-parser.js`：超星章节、新旧作业页面适配、题型、数学表达式、共用材料、作答区域与控件关联。
- `question-context.js`：文档、题干和控件身份快照与变化校验。
- `question-actions.js`：原生选项、隐藏保存字段、匹配题、普通文本和已存在的 UEditor 实例回填与结果检查。

`manifest.json` 记录固定提交及各文件 SHA-256，JS 测试核验文件未被修改。完整 MIT 声明在模块目录及 App“关于与开源许可”中保留。

没有引入课程自动播放、刷课队列、上游设置面板、油猴存储和网络接口。API Key 始终保留在原生加密存储；请求与 SSE 仍由 Kotlin 网络层处理。

## Android 适配

| 文件 | 职责 |
| --- | --- |
| `assets/scripts/question_engine.js` | 上游依赖适配、序列化题目、多空题投影、原生选项键保留、异步回填和停止命令 |
| `data/web/OfficialQuestionReader.kt` | 在官方 HTTPS 来源注册 document-start 脚本及 WebMessage 桥；分别读取跨来源官方 iframe，将答案定向发回原题目文档 |
| `domain/model/AppModels.kt` | 题目、图片、页面和框架模型；原题号及子题说明与全局唯一作答区域 ID 分开 |
| `data/ai/AiAnswerCodec.kt` | 兼容 App 和上游的结构化答案格式，严格校验题号和数量 |
| `data/ai/AiImageLoader.kt` | 从官方来源读取图片字节，验证类型、文件头、大小和账号代次；不向模型发送资源 URL、Cookie 或学习通认证参数 |
| `data/session/PlatformReadGate.kt` | 作业/考试 HTTP 读取与图片读取共享单并发及至少 1 秒请求间隔 |

页面重载、题干或选项变化、控件被替换、人工介入和取消会阻止继续回填。已有不同答案保留；已有相同答案单独计数。富文本通过原有编辑器的 `setContent` / `sync` 写入，答案文本转义，不作为 HTML 执行。回填结果区分“已回填 / 已有相同答案 / 跳过 / 待检查”，不把触发点击等同于已成功保存。

单页最多 300 个作答区域。0.3.1 起文字题每批最多 4 个区域，图片题单题独立成批，不再设置图片张数上限；单张最多 20 MB、读取预算 90 秒，移除单题全部图片共享的 40 秒限制。逐张显示进度，失败明确指出第几张，整题不发送不完整图片，可用“补全”重试。支持官方域名内的受限重定向、暂时性故障重试、官方 Referer 与 User-Agent，并按实际文件头识别 PNG/JPEG/WebP/GIF。外部来源仍拒绝。图片不写入磁盘，平台 Cookie 仅用于读取平台图片；AI 请求不携带 Cookie、图片源地址或 Referer。服务端图片数量、请求大小和上下文限制仍由用户选择的模型决定。

## 已知限制

- 上游明确不提供考试答题；当前 App 继续提供考试读取与官方页面查看。
- 不包含未打开的分页、未加载的虚拟列表或需要额外操作才显示的题目。旧版 WebView 缺少桥能力时只读取主文档，并提示升级。
- 上游字体映射表在其 manifest 中标为 `upstream-not-specified`，本版没有复制该表及字体解码依赖。混淆字体题会提示并跳过，不能保证所有学校的题干都可读取。
- 图片题需要模型支持图像输入。原生 SVG/canvas 图形、音视频、未明确关联的多空、仍未适配的富文本编辑器及非官方图片来源需要人工处理。
- 0.2.6 使用原生实例和控件归属扩展 UEditor 定位，并支持可编辑文本框/iframe；不再限制旧版单个网址。仍拒绝无法唯一关联或只读的控件。见 [文本回填修复](text-answer-fill-fixes.md)。
- 模型生成、批改正确率、官方保存行为和学校页面兼容性需用真实账号验收；构建与合成测试不能替代真机验证。
