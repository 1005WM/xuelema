# 多空填空题回填修复（0.3.10）

同题多个答案框没有完整 label / aria-labelledby 关联时，旧适配器无法拆分作答区域；富文本适配器也只接受同题唯一的 UEditor。

本次在 Android 扩展中按同一填空题的答案字段顺序建立独立空位，每空保持稳定 ID，AI 收到完整题干及空位提示，沿用已有协议逐空生成并回填。完整原生标签保持原有处理，部分标签保留在对应空的提示中。多个 UEditor 通过现存实例与各自 textarea、iframe、容器及表单关联，用 setContent / sync 写入并核对正文和保存字段。已注册但未就绪的编辑器保留空位 ID，就绪后可以再次回填。

保留手工作答、只读和保存确认保护；重复 ID、跨题共享字段、混合作答控件、字段替换/重排/重命名或表单归属变化会拒绝对应操作。单空不接收多元素答案数组。三个上游模块及校验值不变。

新增 18 项 jsdom 回归，覆盖两空/三空、标点换行、表单数组字段、已有答案、只读、错误答案数量、重复 ID、混合 select、控件替换和重排、字段重命名、多 UEditor、延迟就绪、保存不同步、实例替换及部分标签。原 AI 引擎的无标签双空预期同步更新。

GitHub Actions 先运行完整 JavaScript 回归，再执行 Android Debug 构建、单元测试和 Lint，并上传 APK 与验证报告。检查结果以该分支的 Actions 记录为准。本次会话没有本地 shell 或 Android 环境；尚未进行真机登录及真实平台页面验收。

使用新构建后，重新进入作业或考试并重新识别/生成答案。旧的整题聚合答案不猜测拆分。核对官方页面后由用户手动提交。CI Debug 包使用构建环境生成的 Debug 签名，可能与原安装包签名不同；保留数据的覆盖安装需要原签名密钥。
