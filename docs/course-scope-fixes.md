# 先核对课程状态，再读取作业与考试（0.2.2）

日期：2026-10-28。版本：0.2.2 / versionCode 8。

**0.3.1 更新：** 下文考试“无法关联则不展示”的旧行为已修复。缺少课程字段的考试保留并标注“课程待确认”，仅明确关联到结课或未开放课程的考试被排除；读取失败也不再清除待确认考试缓存。作业和课程生命周期规则保持不变。当前行为见 [图片与考试修复记录](image-exam-fixes.md)。

## 行为变化

1. 每次刷新先读取最新课程列表及分页，逐张课程卡片识别状态。
2. `课程已结束`、`已结课` 标记对应的课程直接跳过，不请求其课程签名、作业列表或作业详情。未开放课程也跳过。即使内存中还有上次读取的签名，也必须先通过本次状态检查。
3. 已确认结课或未开放课程的旧作业从 Room 快照移除，首页列表和 `OverviewSummary` 沿用同一 Flow 更新；局部合并、详情补充不会重新加入这些旧作业。
4. 尚未识别的状态、缺少必要标识或互相冲突的课程记录不继续扫描，并提示用户核对。未知课程使作业快照保持 `PARTIAL`，不能宣称全量同步或全部完成。其他未确认课程的旧作业缓存保留。
5. 所有课程均已确认结课/未开放时，只读取账号主页和课程目录，不请求作业与考试列表，并发布当前范围内的空列表。

课程生命周期独立于作业完成状态和考试时间：不会因为作业全部完成、考试已结束或课程名称含“已结课”就认定课程结课。

## 状态依据与边界

课程卡片的 `.not-open-tip` 提示、隐藏标识 `courseId / clazzId / cpi / curPersonId` 的页面契约参考了 [chaoxing-cli 的课程列表读取实现](https://github.com/menghuanshiguang/chaoxing-cli/blob/main/chaoxing.py)。使用独立 Kotlin / Jsoup 实现；按卡片隔离读取，忽略 HTML `hidden` 和内联隐藏的提示，避免相邻课程状态串入。已知结构且没有阻挡提示的课程视为进行中；出现未知提示则视为未知。已结束课程即使没有 `cpi`，仍可凭课程/班级标识排除和清理缓存。

这仍依赖官方内部网页的结构，无法保证学校定制页面或后续改版完全兼容；未使用真实账号验证。

## 考试入口的实际限制

[xuexitong-cli/MCP 文档](https://github.com/DanMo661/Xuexitong-mcp/blob/main/README.md) 提供的是全账号考试汇总入口，没有可确认的按课程过滤参数。因此本版先取得课程状态，再读取一次汇总列表及其必要分页，按明确课程/班级标识过滤返回记录；没有逐门进入结课课程，也不进入考试详情。

仅保留唯一匹配到未结课课程的考试。标识优先，独立课程名称只有在全部班级中唯一时才作为兜底；不根据考试标题猜测课程。所属课程不明或标识冲突的考试不展示，提示数量并保留“打开官方考试列表”入口。若学校汇总页没有提供任何课程关联字段，App 可能无法展示该页考试，需要用户在官方列表查看；不宣称能在服务端排除所有结课考试记录。

课程目录读取失败时不会启动考试请求。已确认的未结课课程作业读取失败时，仍可读取这些课程的考试。已结课和无法关联到有效课程的旧考试缓存会先移除；其余旧缓存沿用原更新时间，不伪装成新数据。
