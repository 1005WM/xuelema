# 「薄荷学习手帐」UI 改版

日期：2026-10-28。保留 Kotlin、Jetpack Compose / Material 3、数据层、AI 与官方网页流程。

## 设计 brief

面向需要查看课程作业、按截止时间安排学习、核对 AI 答案的学生。希望传达安静、可靠、从容的感觉。比较了「日程轴」（时间驱动）、「学习工作台」（工具驱动）与「薄荷学习手帐」（任务与纸张隐喻）后，选择手帐方向，延续原有薄荷绿图标。

以纸白为底、墨绿为标题与操作色、柔和薄荷绿为总览色；危险状态单独使用暖红。依靠字号、字重、留白和对齐建立层级，减少重复说明和描边。不引入无用途的插画、渐变或装饰动画。保留系统字体、大字体支持、浅深主题、系统辅助色和原生触控控件。

首页按「待完成总览 → 筛选 → 任务」组织；总览和任务整体滚动，避免小屏固定头部挤占列表。作业卡按「科目 → 标题 → 截止时间 → 补充日期」组织。设置按「外观 → AI 连接 → 生成偏好 → 数据与账号」分组，保存操作固定在底部。AI 面板将主操作固定在底部、逐题结果留在答案卡中。考试页使用同一阅读层级。

## 验收方式

通过 `DesignReviewTest` 在实际 Android 运行环境中渲染生产 Composable，使用明确标识的合成数据，不登录真实账号、不调用 AI 服务。截图由 Android `UiAutomation.takeScreenshot()` 捕获。覆盖浅色/深色首页、筛选空态、设置、考试和 AI 面板，并验证相关操作回调；另外检查窄屏及大字体。

截图评审最多两轮，每轮只修正最有影响的 1–3 项问题。视觉评审与功能测试分别记录；编译通过不作为截图验收依据。

## 两轮精修

初稿在 Android 15 / API 35、1080×2400、440dpi 的真实模拟器上运行并截图。独立评审仅获取图片和 brief，未读实现。第一轮集中修正三个问题：总览过高、设置保存范围不清、AI 回填失败状态分散。压缩问候与统计区，删除重复口号；明确外观自动保存及底部 AI 保存动作；答案顶部显示已确认数量并提供待处理题定位。常规首页首屏由一张完整作业卡增加至两张。

第二轮结合一次 320dp / 1.3 倍字体探索截图，修正搜索提示换行、设置标签与按钮断字、AI 固定说明挤占阅读区。主题入口简称“系统”并保留跟随系统说明，按钮按空间使用短文案；AI 说明改随题目滚动，主操作保留在底部。成功回填后不再重复显示“答案框可能无法定位”的提示。两轮后停止视觉精修，没有增加装饰媒体。

按用户后续要求停止扩展分辨率测评，最终复核使用常规手机视口。窄屏目录保留第二轮之前的探索证据，不代表最终界面，也不宣称已完成全尺寸验收。独立审美评分分别为 7.2、7.3；第二次评审包含精修前的窄屏问题，评分仅为评审意见，不作为验收指标。

## 功能验证与限制

- 13 项 Android 设备测试通过：课程筛选、完成状态切换、作业入口及设置/考试/官方入口回调、主题即时生效、模型选择、旧 Key 替换、随机性说明、外观独立持久化，以及 AI 回填按钮与待处理题跳转。
- 147 项 JVM 测试全部通过；既有列表脚本、AI 题目引擎 25 项、文本回填 15 项、格式兼容 23 项回归通过。
- Debug、设备测试 APK、Release 构建通过；lint 为 0 错误、11 条提示（依赖更新、组件参数约定和既有 View/KTX 写法）。版本为 0.3.0 / code 15。
- 截图捕获等待 Android 显示帧稳定；没有对截图进行合成或修图。设备测试宿主的系统导航条外观与正式 Activity 的边到边窗口可能不同。
- 真实学校登录、真实课程、真实网页控件和外部 AI 服务仍未验证。没有进行 TalkBack、全尺寸矩阵及实体手机验收；不以截图或回调测试宣称真实平台回填兼容已获确认。
