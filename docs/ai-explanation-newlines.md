# AI 解析换行显示修复（0.3.12）

AI 服务有时会在 explanation / reason 字段中重复转义换行。标准 JSON 解析后仍残留反斜杠和字母 n，界面与“复制全部”会原样显示。

在 AI 答案解析入口统一修正解析正文中的转义换行，支持重复转义、Windows CRLF、连续空行及中英文步骤。保护 Markdown 代码片段、数学定界区域、LaTeX 环境、常见正文 TeX 命令与 Windows 路径。只处理解析字段；answer 保持原值，避免改变实际作答或回填内容。超过已有长度上限的原始解析仍拒绝，空白换行不能满足填空题步骤要求。提示词同步要求标准 JSON 换行转义。

新增 8 项单元回归，覆盖解码入口、reason 兼容、幂等性、英文步骤、公式、代码、路径与空白步骤；设备测试使用多余转义的模拟响应，确认界面显示真实换行且答案框仍为最终答案。

工作流运行完整 JavaScript 回归、Android 构建/单元测试/Lint、测试 APK 编译及 API 35 的 7 项设备回归。结果以当前提交的 Actions 记录为准。此版保留此前多空回填、启动/手动读取和答案滚动修复。APK 仍使用 CI Debug 签名，不能在缺少原密钥时保证与旧包签名一致。
