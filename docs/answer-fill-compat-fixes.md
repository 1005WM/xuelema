# 答案回填兼容与逐题反馈（0.2.8）

日期：2026-10-28。版本：0.2.8 / versionCode 14。

用户反馈所有题目在回填时被跳过，界面没有显示具体原因。未获得实际页面 HTML 或跳过文案，当前无法确认用户学校页面的唯一根因。本次修复代码中可以复现的两类兼容缺口，并增加逐题反馈，方便真实页面继续定位。

## 修复内容

- 选择题接受小写、全角字母、`答案：B`、`**B**`、JSON 字符串数组及与原选项一致的 `B. 选项内容`。也支持唯一匹配的完整选项文本。内部仍使用原生选项键；不按位置猜测、不从解析长句中抽取字母，不接受字母与选项内容冲突的答案或重复文本的歧义匹配。
- 兼容同题唯一可编辑正文 / iframe 与隐藏 textarea 保存字段的组合。之前因为题目内已存在 textarea，这类编辑器没有进入文本适配路径。现在使用可编辑正文写入，保留原生事件同步，并核对隐藏字段；不同步时显示“待检查”。可见 textarea、多保存字段、只读控件、已有不同答案和控件替换仍会阻止写入。
- 每张答案卡片显示“已回填 / 已有相同答案 / 未回填及原因 / 待检查及原因”。WebView 结果按框架命名空间映射到原题 ID，避免多个 iframe 中的同名题号串位。
- 总结果保留全部失败原因，不再只取前五条。答案格式错误使用明确的回填错误，不再使用模型解析文本充当失败原因；答案与框架无法对应时直接报错。
- 保留三个固定上游模块及其哈希，生产脚本和回归测试仍使用相同的组合加载方式。

## 验证与使用

新增 23 个 JS 回归，覆盖选择题格式、原生键、多选、判断、歧义拒绝、不覆盖手工作答、隐藏 textarea 同步及不同步、控件替换、可见 textarea 拒绝和 iframe 编辑器。原有 25 个 AI 引擎与 15 个文本回填场景继续通过。

覆盖安装 `dist/XieLeMa-0.2.8-debug.apk`，重新进入作业页面，生成并核对答案后点击“回填页面”。每张答案卡片顶部会显示该题实际结果。仍需在用户学校页面验证，合成测试不代表已证明所有真实题型可填；本次没有连接设备或调用真实 AI 服务。
